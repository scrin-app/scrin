# scrin brand 0.1.0 — roll-out for the integrating agent

The brand pack touched **only `brand/**`**. Copy each source below to its target; do not hand-edit the
copies — rebuild in `brand/` and re-copy. All paths are relative to the repo root. Sources are
generated by `brand/scripts/{build,render}.mjs`.

Status of targets on 2026-10-04: `apps/web/public/` exists (old gradient `icon.svg`); `apps/desktop/src-tauri/icons/`
**does not exist yet**; `android/` **does not exist yet** — create the paths when those apps land.

```json

  { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" },
  { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any" },

  { "src": "/icon.svg", "sizes": "any", "type": "image/svg+xml", "purpose": "any" }

```

(Never `"any maskable"`; the current file lists `icon.svg` as maskable — remove that.)

**`apps/web/src/components/logo.tsx`** — replace the monitor drawing with the mark (24 viewBox).
The halves use the theme so they follow the accent preset; brand colours are only for the icon:

```tsx
// paths from brand/dist/motion/logo-motion.ts → SCRIN_MARK
<svg viewBox="0 0 24 24" aria-hidden className="size-8 shrink-0">
  <g transform="translate(12 12) scale(0.86) translate(-12 -12)">
    <g className="scrin-mark" fill="none" strokeWidth={3} strokeLinejoin="round">
      <path d={SCRIN_MARK.ivory} className="stroke-fg" />
      <path d={SCRIN_MARK.lagoon} className="stroke-accent" />
    </g>
  </g>
</svg>
```

Keep the text "scrin" in Inter 600 for now or use `brand/logo/wordmark-on-{dark,light}.svg`
(inline, `fill`/`stroke` → `currentColor`). Never put a `transform` attribute on `.scrin-mark`
itself (motion transforms replace it). Use `<MotionConfig reducedMotion="user">` around Motion use.

## 5. Fonts
